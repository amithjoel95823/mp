Personalized Recommendation System Using GNN

An interactive implementation of LightGCN (He et al., SIGIR 2020): collaborative filtering that keeps only neighborhood aggregation, with no feature transformation and no nonlinearity. Train it live in your browser and watch it beat plain matrix factorization.

Same parameter count

Only layer-0 ID embeddings are trained.

Nodes in a user-item graph carry only one-hot IDs with no semantics, so stacked nonlinear transformations make training harder without adding value. LightGCN keeps the one part that matters: smoothing embeddings across neighbors.

How it works

1. Propagation

e_u⁽ᵏ⁺¹⁾ = Σ_{i∈N_u} e_i⁽ᵏ⁾ / √(|N_u||N_i|)

Normalized neighbor sum only. No W, no σ, no self-loop.

2. Layer combination

e_u = Σ_k α_k e_u⁽ᵏ⁾, α_k = 1/(K+1)

Counters over-smoothing and subsumes self-connections.

3. Prediction + loss

ŷ_ui = e_uᵀ e_iL = −Σ ln σ(ŷ_ui − ŷ_uj) + λ‖E⁽⁰⁾‖²

Pairwise Bayesian Personalized Ranking.

Matrix form: E = Σ α_k Â^k E⁽⁰⁾ with Â = D^-½ A D^-½. Because the model is linear, this page backpropagates exactly: ∂L/∂E⁽⁰⁾ = Σ α_k Â^k (∂L/∂E).
